<ui-card>

Component

Kortcontainer med media-, header-, body- og footer-slots. Container query skifter til horisontalt layout i brede containere.

Standardkort Hover-elevation, header og footer. Footer vises kun når slotten har indhold.
Læs mere
Klikbart kort Hele kortet er en knap — klik, Enter eller mellemrum udløser ui-card-click.
Responsivt (container query)
Responsivt kort I containere bredere end 480px lægger media-slotten sig til venstre for indholdet — prøv at ændre vinduets bredde.
<ui-card hoverable clickable responsive> <img slot="media" src="..." alt="..." /> <span slot="header">Title</span> Body content <div slot="footer"><ui-button size="sm">Action</ui-button></div> </ui-card>
Attributter hoverable clickable responsive
Events ui-card-click
Slots media header (default) footer
CSS Parts base header body footer

<ui-icon>

Component

SVG-ikoner med indbygget ikonsæt. Arver tekstfarven via currentColor. Dekorative ikoner er aria-hidden; brug label-attributten for semantiske ikoner.

Størrelser

<ui-input>

Form

Tekstfelt med label, hjælpetekst og fejlbesked. Form-associeret via ElementInternals — deltager i native form submit, reset og validering.

Overlay

Modal dialog bygget på det native <dialog>-element: fokus-trap, Escape og backdrop følger med gratis. Persistent-tilstand blokerer Escape og backdrop-klik.
