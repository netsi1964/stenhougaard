Kodeeksempel

HTML
<!-- Importer komponent --> <script type="module" src="src/components/button/ui-button.js"></script> <!-- Primær knap --> <ui-button variant="primary">Klik mig</ui-button> <!-- Med ikon og loading --> <ui-button variant="primary" loading> <svg slot="icon-start" ...>...</svg> Gemmer... </ui-button> <!-- Fuld bredde, stor --> <ui-button variant="primary" size="lg" full-width> Fortsæt </ui-button> <!-- Lyt på ui-click event --> <script> document.querySelector('ui-button').addEventListener('ui-click', (e) => { console.log('Klikket!', e.detail.originalEvent); }); </script>

Attributter

API
Attribut Type Standard Beskrivelse
variant string 'primary' Visuel stil: primary, secondary, ghost, danger, neutral
size string 'md' Størrelse: sm, md, lg
disabled boolean false Deaktiverer knappen og blokerer interaktion
loading boolean false Viser loading-spinner, blokerer klik
full-width boolean false Strækker knappen til 100% bredde af forælderen
type string 'button' HTML button type: button, submit, reset

Events

Event Detail Hvornår
ui-click { originalEvent: MouseEvent } Ved klik, medmindre disabled eller loading
